# Easy Challenges

本目录包含 19 道 GPU 算子题，主要覆盖以下模式：

| 类型 | 题目 |
| --- | --- |
| 逐元素一元算子 | ReLU、Leaky ReLU、Sigmoid、SiLU、Value Clipping |
| 逐元素二元算术 | Vector Addition、Matrix Addition |
| 数据搬运与索引重排 | Reverse Array、Matrix Copy、Matrix Transpose、Interleave Arrays |
| 拆分与融合激活 | SwiGLU、GEGLU |
| 滑动窗口与线性代数 | 1D Convolution、Matrix Multiplication、Simple Inference |
| 图像处理 | Color Inversion、RGB to Grayscale |
| 迭代整数运算 | Rainbow Table（重复 FNV-1a 哈希） |

题目目录按 `<编号>_<名称>` 命名；每题包含题目说明、参考实现和对应的 CUDA/Triton starter 模板。
